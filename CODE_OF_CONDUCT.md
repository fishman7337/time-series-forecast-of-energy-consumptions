# Code of Conduct

## Our Standard

This repository should remain a respectful learning and collaboration space.
Contributors are expected to:

- Use welcoming and professional language.
- Give feedback that is specific, constructive, and kind.
- Respect different experience levels and learning contexts.
- Keep discussions focused on the project and its academic goals.
- Avoid harassment, personal attacks, discriminatory language, or disclosure of
  private information.

## Scope

This code of conduct applies to repository discussions, issues, pull requests,
documentation, and any related collaboration channel.

## Reporting

If you notice behaviour that does not meet this standard, contact the repository
maintainer privately where possible. Reports should include the context, links,
and the outcome requested.

## Enforcement

Maintainers may remove comments, close threads, reject contributions, or limit
access when behaviour harms the learning environment or project integrity.
